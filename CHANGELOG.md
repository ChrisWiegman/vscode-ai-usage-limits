## 0.3.0 - 2026-05-12

### Features

* Merge Claude and Codex into a single combined status bar item that shows both providers side-by-side
* Add startup and refresh diagnostic logging to the AI Limits output channel

### Bug Fixes

* Cancel pending debounce timer on deactivation to prevent updates to disposed status bar items
* Use async exec instead of execSync for macOS Keychain lookup to avoid blocking the VS Code extension host event loop
* Add per-request HTTP timeout via AbortController in fetchWithRetry to prevent indefinitely-hanging fetch calls
* Show status bar in loading state immediately on activation so it is populated before the first async refresh completes

### Chores

* Switch from Biome to ESLint for linting
